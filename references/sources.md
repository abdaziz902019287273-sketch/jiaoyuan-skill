# 原文检索与来源

在用户问具体篇目、原话、出处、历史细节，或需要说明技能来源时读取。

## 三个层次不可混写

1. **原文**：从实际读取的可靠文本逐字核对，给篇名及可定位出处。需要时核对年代、版本和上下文。
2. **方法概括**：对原著思想或上游提炼的转述，不加引号冒充原话。
3. **现代应用**：将方法用于产品、个人、组织等情境，以及本技能新增的可证伪假设、试验设计、资源上限和退出规则。明确是现代解释，不倒写成历史作者已经提出的原理。

上游技能及其研究笔记是二次解释，不能仅凭其中的“证据”“已验证”标记认定历史事实。思想相似也不能证明直接影响关系。历史案例不因结局成功就成为当代策略的充分证据。

## 可选原文库：按需发现

普通现实分析不要求安装全文库。首次需要原文时再查找，不在激活时扫描磁盘。

1. 用户提供的文件、目录或链接优先。
2. 检查 `MAOXUAN_KB_PATH` 环境变量。PowerShell 用 `$env:MAOXUAN_KB_PATH`；POSIX shell 用 `${MAOXUAN_KB_PATH}`；Python 用 `os.environ.get('MAOXUAN_KB_PATH')`。仅读取，不自动修改环境。
3. 如未提供路径，可检查当前目录、父目录、用户主目录下的 `MaoZeDongAnthology`，以存在 `src/目录.md` 为一种识别信号。其他用户指定格式则读取实际目录，不能因格式不同直接否定。
4. 没有找到，本次会话不反复查找；用户提供新路径后重新检查。不自动下载整库。

兼容的第三方数字化库：[weiyinfu/MaoZeDongAnthology](https://github.com/weiyinfu/MaoZeDongAnthology)。此链接仅作可选资源入口，不表示已安装、已逐篇校勘或有权任意再分发。

使用 `rg --files` 按篇名找文件，或 `rg -n` 按关键词定位段落，再读取足够上下文。以实际目录为准，不硬编码篇目编号、文章数量或卷次。编者导读、注释、附录与正文必须区分。

找不到本地原文时，若可联网，查可信的原文发布或可靠版本；转载与 OCR 需留意错字和删节。无法核实则说明未核，改作概括；用户明确要精确引语时，不能静默跳过查证仍声称完成。

页码依版本而变。没有见到对应版面不要猜页码。引用历史文字后，解释其所针对的问题、成立条件及现代迁移的差异。
